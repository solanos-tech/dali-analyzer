# dali-analyzer frontend

React + Vite frontend for DALI frames monitoring.

## Run locally

```powershell
npm ci
npm run dev
```

## Build and lint

```powershell
npm run lint
npm run build
```

## Runtime config

- `VITE_API_BASE_URL` optional API base URL
- `VITE_API_PROXY_TARGET` dev proxy target (default `http://127.0.0.1:8000`)
